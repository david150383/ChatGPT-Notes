If an interviewer asks you to **write pseudocode**, they usually want to see your **logic and problem-solving approach**, not perfect programming syntax.

### What to write

Use simple, language-independent steps:

```text
START

1. Take the required input
2. Initialize necessary variables
3. Process the input using loops/conditions
4. Store or update the result
5. Display/return the result

END
```

### Example: Find the largest number in an array

```text
START

INPUT array

max = first element of array

FOR each number in array
    IF number > max
        max = number
    END IF
END FOR

OUTPUT max

END
```

You don't need to worry about whether it's exactly Java, Python, C++, etc.

### Good pseudocode keywords

Use words like:

* `INPUT`
* `OUTPUT`
* `IF / ELSE`
* `FOR`
* `WHILE`
* `FUNCTION`
* `RETURN`
* `INITIALIZE`
* `END`

### Interview tip

Before writing pseudocode, **explain your approach in 1–2 sentences**:

> "First, I'll initialize the maximum with the first element. Then I'll iterate through the array and update the maximum whenever I find a larger value."

Then write the pseudocode.
